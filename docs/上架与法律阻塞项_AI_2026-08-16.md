## 三、一个必须知道的顺序依赖

**E3 不修,E1 就是空的。**

危机协议写在 `agent-chat` 的 prompt 里,而 `agent-chat` 由数据库触发器通过 `pg_net` 调用。
现在那个 URL 解析不了,请求根本到不了函数——**协议写得再好也不会执行**。

同理,`trigger_agent_chat_reply` 末尾是 `exception when others then return new`,
失败会被静默吞掉。这意味着**危机协议失效时不会有任何告警**。

建议:E3 先修,然后用一条测试消息实际验证 E1 真的触发。

## 四、关于 SB 243 的额外提醒

- **个人可直接起诉**,$1,000/次起,加律师费。不需要监管机构介入。

  它证明你知道该做、也知道怎么做,只是没上线。这就是为什么 E1/E3 排最前。

  那需要把危机事件**落库成结构化记录**,不能只靠 prompt。**今天不用做,但架构上要预留。**
